# DanialTools 🛠️

**A Python utility library made by Danial**

DanialTools is a beginner-friendly Python utility library that provides useful tools for everyday programming tasks.
## You can download my library with (pip install danialtools)

## ✨ Features

Currently included tools:

- 🔐 **Password Generator** – Generate random passwords.
- 🛡️ **Password Strength Checker** – Check password strength.
- 🔢 **Verification Code Generator** – Generate random verification codes.
- 📝 **Text Counter** – Count words and letters in text.

## 🚀 Getting Started

### Requirements
- Python 3

### Run the project

```bash
git clone https://github.com/danielyazdanjou1394-tech/DanialTools.git
cd DanialTools
python3 main.py
```
